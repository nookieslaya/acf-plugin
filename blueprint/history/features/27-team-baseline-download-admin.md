# Feature: Team baseline download in Admin

**From build-plan:** feature 27
**Status:** verified

## Goal

Let an administrator download the currently approved snapshot as
`acf-schema-baseline.json` from History. The download uses the same portable
format accepted by the existing WP-CLI baseline check, allowing a team to save
and commit it without using WP-CLI for export.

## In scope

- A History action available only when an approved baseline exists.
- A protected Admin POST download endpoint using the existing administrator
  capability and a dedicated nonce.
- A response generated by the existing `SchemaBaselineFile` encoder from the
  approved snapshot schema, not the live runtime schema.
- History guidance with the baseline snapshot ID and capture time, plus an
  explicit save-to-repository and Git-commit handoff.
- English and Polish documentation, translated Admin strings, and focused
  assertion coverage.

## Out of scope

- Writing, importing, replacing, or locating files in a theme or repository.
- Git commands, commits, pushes, or hosting-service connections.
- Changes to WP-CLI export/check commands, baseline approval rules, or review
  records.
- Detecting whether a downloaded baseline was committed later.

## Data / contracts

- The fixed download filename is `acf-schema-baseline.json`.
- The body remains the version-1 `SchemaBaselineFile` document with
  `format_version`, `schema_version`, and `schema`.
- The schema is exactly the active approved snapshot schema. The action creates
  no snapshot or review record, changes no option, writes no filesystem path,
  and runs no Git operation.
- The endpoint is `admin_post_acf_schema_guard_download_approved_baseline` and
  requires `manage_options` plus the
  `acf_schema_guard_download_approved_baseline` nonce.
